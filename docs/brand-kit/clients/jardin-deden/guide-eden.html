En un coup d'œil
01 · Comment ça marche

Le système fait le travail
administratif. Vous décidez.

Concrètement : quand un parent vous écrit pour inscrire son enfant, le système lui envoie le dossier à remplir. Quand le parent renvoie ses documents, le système les lit, vérifie que tout est là, et vous demande de valider. Si vous validez, l'enfant est ajouté à votre fichier et le parent reçoit sa confirmation. Vous n'écrivez plus rien à la main.

Votre seul geste au quotidien
Quand un parent vous écrit pour une inscription
Vous glissez son email dans le dossier Outlook « 1 - Nouvelle inscription ».  C'est tout. Le système s'occupe du reste.

Le reste du temps, vous recevez simplement un email quand un dossier complet est prêt à être validé. Vous vérifiez, vous corrigez si besoin, vous validez (ou refusez). Deux clics.

Ce qui ne change pas pour vous
Vos repères restent les mêmes
Vous restez dans votre boîte Outlook habituelle.
Règles inchangées : entrées le 1er du mois, temps plein.
Vos communications de virement KBC gardent le même format.
Le fichier reste le vôtre, dans votre Drive.
Un geste pour vous, tout le reste automatisé. lucid-lab.fr

Vous validez et corrigez
04 · Le formulaire de validation

Vous voyez tout, vous corrigez tout,
puis vous validez.

Quand vous cliquez sur « Vérifier et corriger » dans l'email, vous ouvrez un formulaire avec toutes les informations déjà remplies (lues dans le dossier). Vous corrigez ce qui est faux (les champs en orange sont ceux à vérifier en priorité), vous choisissez Valider ou Refuser, et vous enregistrez. Ce sont vos valeurs corrigées qui sont écrites, pas la lecture brute.

Exemple : ici un nom manuscrit mal lu (« Bouron » au lieu de « Gouron »). Vous le corrigez dans le champ, et c'est le bon nom qui entre dans le fichier.

Ce qui se passe s'il y a un problème
Pièce manquante
Dossier incomplet

Le système relance directement le parent en listant ce qui manque, et il ne revient vers vous que quand le dossier est complet. Vous n'êtes pas dérangée.

Écriture à la main
Un mot mal lu

Vous le voyez dans le formulaire et vous le corrigez avant de valider. Rien de faux n'entre dans le fichier. Astuce : demandez aux parents de remplir en MAJUSCULES, la lecture est alors quasi parfaite.

Incohérence
Une date qui cloche

Signalée dans « Points d'attention » du formulaire (par exemple une date d'entrée qui n'est pas un 1er du mois). Vous décidez de valider, corriger ou refuser.

Une lecture douteuse est toujours rattrapée par vous. lucid-lab.fr

À faire · à ne pas faire
05 · Vos repères

Ce qu'il faut faire,
et ce qu'il ne faut pas toucher.

À faire
  • Glisser les emails d'inscription dans le dossier « 1 - Nouvelle inscription ».
  • Ouvrir le formulaire de validation, vérifier les informations, corriger si besoin, puis Valider ou Refuser.
  • Vérifier surtout le nom et les dates quand le dossier est manuscrit.
  • Encourager les parents à remplir en MAJUSCULES, ou à remplir le PDF sur ordinateur.
À ne pas faire
  • Ne pas supprimer ni renommer les dossiers Outlook « 1 - Nouvelle inscription » et « 2 - Pack envoyé » : ils déclenchent tout.
  • Ne plus travailler dans l'ancien Excel (le .xlsm est archivé) : le Google Sheet est désormais la seule référence.
  • Ne pas modifier les colonnes techniques ni les formules du fichier (onglet PRESENCE, compteurs). Corriger une valeur, oui ; casser une formule, non.
  • Ne pas valider un dossier sans l'avoir regardé, surtout un nom manuscrit.
